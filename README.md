# Project Context Pack

Read these files before implementing features:

1. `project-context-updated.md` — product requirements and workflows.
2. `architecture-context-updated.md` — architecture and system boundaries.
3. `code-standards-updated.md` — coding, testing, and security conventions.
4. `ui-context-updated.md` — UI, accessibility, Framer Motion, and GSAP rules.
5. `progress-tracker-updated.md` — verified status and open decisions.
6. `ai-workflow-rules-context-updated.md` — AI-agent working procedure.

The progress tracker distinguishes documentation completed from application implementation that has not yet been verified. Do not assume planning documents mean code has been built.
